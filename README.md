# FreelanceRadar Bot

Telegram бот для моніторингу нових замовлень на Freelancehunt з AI-генерацією відгуків.

## Запуск

### 1. Встанови Python
Завантаж з https://python.org (версія 3.10+)
При встановленні постав галочку "Add Python to PATH"

### 2. Відкрий папку в терміналі
Натисни правою кнопкою на папку FreelanceRadarBot → "Відкрити в терміналі"

### 3. Встанови залежності
```
pip install -r requirements.txt
```

### 4. Запусти бота
```
python bot.py
```

## Команди в Telegram
- /start — запустити бота
- /check — перевірити зараз
- /clear — очистити історію
- /status — статус бота

## Як працює
1. Бот перевіряє нові замовлення кожні 2 хвилини
2. Надсилає тобі картку замовлення з бюджетом та навичками
3. Кнопка "Згенерувати відклик" — AI створює персональний відклик
4. Копіюєш і відправляєш на фрілансхант
